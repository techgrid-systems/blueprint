File 01 // The Engine

monitor.php

The automated worker that pings your tech stack.

Dual-Protocol Logic

Checks Web URLs via cURL and Raw IPs (like 8.8.8.8) via Sockets.

if (filter_var($url, FILTER_VALIDATE_IP)) {
  $conn = @fsockopen($url, 53);
  $status = $conn ? 'up' : 'down';
} else {
  $ch = curl_init($url);
  curl_exec($ch);
  $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
}
